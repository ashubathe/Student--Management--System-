# Student--Management--System-
Student: Ashwini Vinayak Bathe

Student Management System is a Java-based console application designed to manage student records efficiently. It allows users to add, display, search, update, and delete student details. It also calculates percentages and grades automatically using Java concepts such as classes, objects, ArrayList, methods, loops, and exception handling.

## About the Project
Student Management System is a Java-based console application designed to manage student records efficiently without using a database.
## Features
- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Calculate Percentage and Grade
- Exit Application
## Technologies Used
- Java, VS Code,ArrayList
## Concepts Used
- Classes and Objects,Constructors,Methods,Loops,Switch Case,Exception Handling
